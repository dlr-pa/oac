Multiple emission inventories

In this example, no time evolution file is given, but multiple emission inventories are given as input. OpenAirClim will interpolate between discrete inventory years.

Imports

If the openairclim package cannot be imported, make sure that you have installed openairclim properly (see User Guide → Installation).

import numpy as np
import xarray as xr
import matplotlib.pyplot as plt
from openairclim.utils.create_artificial_inventories import (
    ArtificialInventoryDict,
    convert_xr_dict_to_nc,
)
import openairclim as oac

xr.set_options(display_expand_attrs=False)

Input files

In order to be able to execute this example simulation, two types of input are required.

  • Configuration file multi_inv.toml

  • Emission inventories rnd_inv_20XX.nc

Emission inventories

  • Artificial (random) emission inventories generated with OpenAirClim

  • Inventory years: 2000, 2020, 2040, 2060, 2080, 2100

  • Emissions increase linearly with each year (relative to 2000)

The inventories are generated in the input directory of this demo. The random seed is fixed so that the example gives reproducible results.

np.random.seed(42)
rnd_inv_dict = ArtificialInventoryDict(year_arr=[2000, 2020, 2040, 2060, 2080, 2100]).create()
convert_xr_dict_to_nc(rnd_inv_dict, prefix="rnd_inv", out_path="../input/")
